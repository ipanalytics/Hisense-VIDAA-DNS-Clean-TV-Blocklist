ad-cmp.hismarttv.com
// This group blocks the most obvious advertising endpoints, campaign assets,
// impression reporting, shopping cards, and other promotional material.
// It normally produces the most visible cleanup of the VIDAA home screen.
// A possible side effect is delayed application artwork after startup:
// VIDAA may first render local placeholders, wait for a blocked remote resource,
// and load an alternative cached or fallback icon several seconds later.
// ad-cmp: inferred advertising or campaign-management component.
